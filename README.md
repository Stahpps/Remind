# Remind

An offline-first Android app for personal events and reminders, created by **Stahpps** with AI assistance.

[Download the latest APK](https://github.com/Stahpps/Remind/releases/latest) · [All releases](https://github.com/Stahpps/Remind/releases) · [Support on Ko-fi](https://ko-fi.com/stahpps)

## Features

- Charcoal dark theme with neon green accents, plus light mode.
- English and Romanian interface selection.
- Upcoming, Today and Past views. Today's events also appear in Upcoming or Past according to their scheduled time.
- Work, Personal, Important and Health categories with matching colors and emoji.
- Create, edit, duplicate and delete events.
- Multiple reminder times per event.
- Native Android notifications, including delivery while the screen is off.
- Optional daily summary at 08:00 by default, with an editable time. Summaries are scheduled only for dates that have saved events.
- A notification sound setting that opens Android's Remind-specific sound controls (Android 8+).
- Event and preference storage on the device using `localStorage`; no account or application backend is required.

## Install on Android

1. Open [Releases](https://github.com/Stahpps/Remind/releases) and download the APK asset for the version you want.
2. Open the APK on your phone and allow installation from that source if Android asks.
3. Allow notifications and, when requested, the **Alarms & reminders** permission.

To keep your saved events, install updates over the existing official release without uninstalling. Uninstalling or clearing the app's storage removes the locally saved data. Back up anything important before doing either.

Android's force-stop, notification restrictions and power-management policies can affect delivery. Closely spaced alerts may also be delayed by Android's idle-mode limits. A daily summary contains the events saved for that date; editing an event updates its pending notifications.

## Develop locally

Requirements:

- Node.js 22.12+ and npm.
- JDK 21 for Android builds.
- Android Studio / Android SDK, including SDK platform 36.

```sh
npm ci
npm run dev
```

Run the checks and create the web bundle:

```sh
npm test
npm run lint
npm run build
```

## Build a debug APK

Configure your Android SDK path using Android Studio or the `ANDROID_HOME` environment variable. Make sure `JAVA_HOME` points to JDK 21.

PowerShell:

```powershell
npm run build
npx cap sync android
cd android
.\gradlew.bat assembleDebug
```

macOS / Linux:

```sh
npm run build
npx cap sync android
cd android
./gradlew assembleDebug
```

Output: `android/app/build/outputs/apk/debug/app-debug.apk`.

Debug builds do not require the maintainer's release-signing files. They use a different signing certificate and cannot update an installed official release directly.

## Build your own signed release

The official release signing key and its passwords are deliberately excluded from this repository.

1. Generate your own Android signing key and keep a secure backup.
2. Copy `android/keystore.properties.example` to `android/keystore.properties`.
3. Fill in your own key location, alias and passwords. The key path is relative to the `android` directory.
4. Run `npm run build`, `npx cap sync android`, and `assembleRelease` with the Android Gradle wrapper.

With signing configured, the APK is written to `android/app/build/outputs/apk/release/app-release.apk`. Without signing configured, a release build is unsigned and must be signed before installation.

Do not commit signing keys, the populated `keystore.properties`, SDK paths, credentials or private environment files. A release signed with your own key cannot replace the official installed app without first uninstalling it.

## Project layout

- `src/App.jsx`: interface and event editing.
- `src/i18n.js`: English and Romanian translations.
- `src/reminders.js`: reminder migration, duplication and notification payloads.
- `src/notification-service.js`: native notification synchronization.
- `src/settings.js`: preference defaults and migration.
- `android/app/src/main/java/com/remind/app/RemindSettingsPlugin.java`: Android notification sound-settings bridge.
- `tests/`: regression tests for event migration, reminders, daily summaries and settings.

## Privacy

Remind stores events and preferences on your device. The app has no application account or server synchronization. Its Ko-fi link opens an external service subject to that service's policies. Notifications are scheduled locally through Android.
