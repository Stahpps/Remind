# Third-party components

Remind uses third-party software. Making this repository public does not change the licenses of those components or extend their licenses to Remind's original source and assets.

The following direct dependencies report MIT licenses in their installed package metadata:

- React and React DOM — https://github.com/facebook/react
- Vite and the React Vite plugin — https://github.com/vitejs/vite
- Tailwind CSS and its Vite integration — https://github.com/tailwindlabs/tailwindcss
- Capacitor Core, Android, CLI and Local Notifications — https://github.com/ionic-team

AndroidX and the Gradle tooling have their own licenses and notices. Preserve the notices distributed with those components. The Android Gradle wrapper scripts include their upstream license headers.

This is an overview, not an exhaustive inventory of every transitive dependency. Exact package versions are recorded in `package-lock.json` and the Android Gradle files; consult the upstream license files distributed with each dependency.
